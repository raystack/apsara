## Anatomy

Import and assemble the component:

```tsx
import { Drawer } from "@raystack/apsara";

<Drawer side="right">
  <Drawer.Trigger />
  <Drawer.SwipeArea />
  <Drawer.Content side="right">
    <Drawer.Header>
      <Drawer.Title />
      <Drawer.Description />
    </Drawer.Header>
    <Drawer.Body />
    <Drawer.Footer />
  </Drawer.Content>
</Drawer>
```

The indent is optional. It wraps your app:

```tsx
<Drawer.Provider>
  <Drawer.Indent>{/* your app, with its drawers */}</Drawer.Indent>
</Drawer.Provider>
```

## Usage

Pick the edge it enters from, then decide who owns its open state.

### Basic

A drawer slides in from the edge named by the `side` of `Drawer.Content` and traps focus while open.

<Demo data={basicDemo} />

### Positioning

The Drawer can slide in from different sides of the screen. Swipe-to-dismiss is automatically configured based on the `side` prop.

<Demo data={positionDemo} />

### Controlled

Pass `open` with `onOpenChange` to own the state. Do this when the drawer has to open from elsewhere on the page, or stay open until a save completes.

<Demo data={controlledDemo} />

### Swipe to open

`Drawer.SwipeArea` is an invisible strip along a screen edge. Users drag from it to open the drawer. It sits on the edge named by `side`. Pass `swipeDirection` to change the drag direction that opens it. While the drawer is closed, the strip sits above the page and takes clicks along that edge. It ignores pointer events while the drawer is open.

The example keeps the drawer inside its box. `Drawer.Content` renders into the box through `container`, and `contain: layout` on the box positions the fixed parts inside it. `modal={false}` keeps the rest of the page usable.

<Demo data={swipeAreaDemo} />

### Forms and the phone keyboard

Set `enableVirtualKeyboard` on `Drawer.Content` when the drawer has form fields. When an input gets focus and the on-screen keyboard opens, the drawer scrolls to keep the input visible, and a bottom drawer moves up above the keyboard. On touch devices, the drawer then handles taps on its inputs itself, so the page does not jump.

Base UI sets `--drawer-keyboard-inset` on the `drawer-viewport` slot while the keyboard is open. Use `var(--drawer-keyboard-inset, 0px)` to lift a pinned footer above the keyboard.

<Demo data={keyboardDemo} />

### Indent

Wrap your app in `Drawer.Provider` and `Drawer.Indent`. While any drawer inside the provider is open, the indent scales down and rounds its top corners, and a background layer shows behind it. The indent and its background (the `drawer-indent-background` slot) get a `data-active` attribute while a drawer is open. The effect follows the swipe as users drag the drawer closed. When the operating system asks for reduced motion, the indent does not move.

`Drawer.Indent` is at least as tall as the screen. The effect scales from the top of the indent, so keep your app's scroll container inside it. On a page that scrolls the whole document, the visible content shifts up instead of down. While a drawer is open, `position: fixed` elements inside the indent scale with it.

The example uses the same box as the swipe area example.

<Demo data={indentDemo} />

## API Reference

The same header, body and footer shell as [Dialog](/docs/components/dialog), anchored to an edge.

### Root

Groups all parts of the drawer. Its `side` prop sets the swipe-to-dismiss direction. `Drawer.Content` has its own `side`, which places the panel. Set both to the same edge.

- Inherits all Base UI Drawer.Trigger props

Renders a button that closes the drawer. `Drawer.Content` already renders one unless `showCloseButton` is `false`.

- Inherits all Base UI Drawer.Close props

### Slots

Every rendered part carries a stable `data-slot` attribute for [styling and testing](/docs/styling#with-data-slot):

| Slot | Element |
|------|---------|
| `drawer-backdrop` | The overlay behind the drawer |
| `drawer-viewport` | Viewport wrapper that positions the drawer |
| `drawer-content` | The drawer panel (popup) |
| `drawer-content-body` | Content wrapper inside the panel |
| `drawer-close` | The built-in close button (when `showCloseButton`) |
| `drawer-header` | The `Drawer.Header` container |
| `drawer-title` | The `Drawer.Title` element |
| `drawer-description` | The `Drawer.Description` element |
| `drawer-body` | The `Drawer.Body` container |
| `drawer-footer` | The `Drawer.Footer` container |
| `drawer-swipe-area` | The `Drawer.SwipeArea` edge zone |
| `drawer-indent` | The `Drawer.Indent` wrapper |
| `drawer-indent-background` | The background layer that `Drawer.Indent` renders |

## Accessibility

- Uses `role="dialog"` with `aria-modal="true"`.
- Focus is trapped within the drawer and restored on close.
- Supports dismissal with Escape key and swipe gestures.
- Default `aria-label` is `"Drawer"`. Pass `aria-label` or `aria-labelledby`
  on `Drawer.Content` to give the dialog a meaningful name.
- Close button label defaults to `"Close"`. Override with the `closeLabel`
  prop for localisation or context-specific copy (e.g. `"Close settings"`).
- Respects motion preferences: drawer slide motion is enabled only when
  `prefers-reduced-motion: no-preference`.
