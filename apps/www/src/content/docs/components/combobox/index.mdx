## Anatomy

Import and assemble the component:

```tsx
import { Combobox } from "@raystack/apsara";

<Combobox>
  <Combobox.Label />
  <Combobox.Input />
  <Combobox.Clear />
  <Combobox.Content>
    <Combobox.Empty />
    <Combobox.Status />
    <Combobox.Group>
      <Combobox.GroupLabel />
      <Combobox.Item />
    </Combobox.Group>
    <Combobox.Separator />
  </Combobox.Content>
</Combobox>
```

## Usage

A combobox filters its list as the user types. The props below cover what the list holds, how many items can be picked, and who owns the value.

### Basic

A simple combobox with search filtering built in. Type to filter options.

### With icons

You can pass the `leadingIcon` prop to `Combobox.Item` to display icons before item text.

<Demo data={iconDemo} />

### With Field

Wrap the Combobox with [Field](/docs/components/field) to add a label, description, and error handling.

<Demo data={withFieldDemo} />

### Groups and separators

Organize items into groups with `Combobox.GroupLabel` and separators. Groups, group labels, and separators are hidden while the user is searching.

<Demo data={groupDemo} />

### Multiple selection

Pass the `multiple` prop to enable multi-select. Selected values appear as chips in the input. Items display checkboxes in multiple mode.

The input shows the first two chips and a "+N" count for the rest. Press Backspace in an empty input to remove the last value. Press Left Arrow at the start of the input to move focus to the chips. On a focused chip, press Backspace or Delete to remove it.

<Demo data={multipleDemo} />

### Label and clear button

`Combobox.Label` renders a visible label linked to the input. `Combobox.Clear` renders a button that clears the value. It shows only when there is a value or input text. Place both anywhere inside `Combobox`.

<Demo data={labelDemo} />

### Empty state

`Combobox.Content` shows "No results" when no item matches the input. To change the text, add `Combobox.Empty` as a direct child of `Combobox.Content`.

<Demo data={emptyDemo} />

### Controlled

Use `value` and `onValueChange` for controlled behavior.

<Demo data={controlledDemo} />

### Using IDs as values

When your app stores IDs instead of item objects, wrap the data with `Combobox.createItems`. `getValue` returns the value that `value` and `onValueChange` use. `getLabel` returns the text shown in the input and used for filtering. Pass a function as the child of `Combobox.Content` to render each item that matches the input.

Create the collection at module scope for static data. For data that changes, wrap it in `React.useMemo` keyed by the data.

<Demo data={createItemsDemo} />

### Slots

Every rendered part carries a stable `data-slot` attribute for [styling and testing](/docs/styling#with-data-slot):

| Slot | Element |
|------|---------|
| `combobox-label` | The label for the input |
| `combobox-input` | The text input that opens the popup |
| `combobox-chips` | The container for chips and the input in multiple mode |
| `combobox-chip` | A selected value in multiple mode |
| `combobox-chip-remove` | The button that removes a chip |
| `combobox-chip-overflow` | The "+N" count of chips that are not shown |
| `combobox-clear` | The button that clears the value |
| `combobox-positioner` | Wrapper that positions the popup |
| `combobox-content` | The popup container |
| `combobox-status` | The hidden live region that announces the number of results |
| `combobox-empty` | The text shown when no item matches |
| `combobox-list` | The scrollable list of items |
| `combobox-group` | A group of related items |
| `combobox-group-label` | The label for a group |
| `combobox-separator` | The divider between items or groups |
| `combobox-item` | A selectable option row |
| `combobox-item-text` | The text label inside an item (when its children is a string) |
| `combobox-item-icon` | The leading icon inside an item (when `leadingIcon` is set) |

## Accessibility

- Follows the [WAI-ARIA Combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)
  via [Base UI Combobox](https://base-ui.com/react/components/combobox): the input
  is a `role="combobox"` with `aria-expanded` and `aria-controls`, the popup list
  is a `listbox`, and each item is an `option` with `aria-selected`.
- Arrow keys move the highlight through visible options, Enter selects the
  highlighted option, and Escape closes the popup, and focus stays in the input
  the whole time, so typing to filter never loses the user's place.
- In multiple mode, each item renders a checkbox that mirrors its selected
  state, and selected values appear in the input as removable chips.
- The chips use Base UI's `Combobox.Chips`, which has `role="toolbar"`. Arrow
  keys move between chips, and Backspace or Delete removes the focused chip.
- `Combobox.Empty` and `Combobox.Status` are polite live regions. Screen
  readers announce "No results" and the number of matching items.
- Group labels use Base UI's `Combobox.GroupLabel`, which links the label to
  its group via `aria-labelledby`, so wrap `Combobox.GroupLabel` in `Combobox.Group`.
- Wrap the Combobox with [Field](/docs/components/field) to associate a
  visible label, description, and error message with the input.
