## Anatomy

Import and assemble the component:

```tsx
import { IconButton } from "@raystack/apsara";

<IconButton />
```

## Usage

An icon-only button built on the Base UI [Button](https://base-ui.com/react/components/button).

### Size

Four steps, 1 through 4. Match the step to the control the button sits beside so their heights agree.

<Demo data={sizeDemo} />

### State

Hover and focus are handled for you. `disabled` stops the button responding and removes it from the tab order.

`loading` shows a spinner in place of the icon and sets `aria-busy`. The button blocks clicks while it loads but stays focusable, so focus is not lost.

<Demo data={stateDemo} />

### Focusable when disabled

`focusableWhenDisabled` keeps a disabled button in the tab order. The button uses `aria-disabled` instead of the native `disabled` attribute.

<Demo data={focusableWhenDisabledDemo} />

### Render as another element

`render` swaps the underlying element and keeps the styles. When `render` is set, `nativeButton` defaults to `false`, so the button role and keyboard handling are added. If `render` returns a real `<button>`, set `nativeButton` to `true`.

<Demo data={renderDemo} />

### Slots

Every rendered part carries a stable `data-slot` attribute for [styling and testing](/docs/styling#with-data-slot):

| Slot | Element |
|------|---------|
| `icon-button` | The root `<button>` element |
| `icon-button-icon` | Wrapper around the icon content |
| `icon-button-loader` | The loading spinner (when `loading`) |

### Styling

The IconButton uses CSS variables for consistent styling across themes:

- Background color uses `--rs-color-background-base-primary`
- Border color uses `--rs-color-border-base-primary`
- Text color uses `--rs-color-foreground-base-primary`
- Hover state uses `--rs-color-background-base-primary-hover`
- Disabled state uses reduced opacity and different background/border colors

## Accessibility

IconButton uses the Base UI Button, which renders a native `<button>` by default:

- Enter and Space activate the button.
- `disabled` sets the native `disabled` attribute. With `focusableWhenDisabled` or `loading`, it sets `aria-disabled` instead.
- `loading` sets `aria-busy="true"`. The spinner has `aria-hidden="true"`.

For better accessibility, make sure to:

- Provide meaningful aria-label when the button's purpose isn't clear from the icon alone
- Consider adding tooltips for icon-only buttons
