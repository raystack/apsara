## Anatomy

Import and assemble the component:

```tsx
import { ContextMenu } from '@raystack/apsara'

<ContextMenu>
  <ContextMenu.Trigger />
  <ContextMenu.Content>
    <ContextMenu.Item />
  </ContextMenu.Content>
</ContextMenu>
```

## API Reference

The ContextMenu component is composed of several parts, each with their own props.

### Root

The root element is the parent component that holds the context menu. Using the `autocomplete` prop, you can enable search functionality.

<auto-type-table path="./props.ts" name="ContextMenuRootProps" />

### Trigger

The area that opens the context menu on right-click or long press. Renders a `<div>` element.

<auto-type-table path="./props.ts" name="ContextMenuTriggerProps" />

### Content

The container that holds the menu items. When autocomplete is enabled, renders an inline search input inside the popup.

<auto-type-table path="./props.ts" name="ContextMenuContentProps" />

### Item

Individual clickable options within the menu. Built on top of [Base UI ContextMenu.Item](https://base-ui.com/react/components/context-menu).

Renders as a `role='option'` when used in an autocomplete menu. By default, the item's `children` text content is used for matching, which can be overridden by passing a `value` prop.

<auto-type-table path="./props.ts" name="ContextMenuItemProps" />

### Group

A way to group related menu items together. When filtering is active, the group wrapper is removed and items are rendered flat.

<auto-type-table path="./props.ts" name="ContextMenuGroupProps" />

### Label

Renders a label in a menu group. This component should be wrapped with ContextMenu.Group so the `aria-labelledby` is correctly set on the group element. Hidden when filtering is active.

<auto-type-table path="./props.ts" name="ContextMenuLabelProps" />

### Separator

Visual divider between menu items or groups. Hidden when filtering is active.

<auto-type-table path="./props.ts" name="ContextMenuSeparatorProps" />

### EmptyState

Placeholder content when there are no menu items to display.

<auto-type-table path="./props.ts" name="ContextMenuEmptyStateProps" />

### Submenu

Wraps a submenu root. Use with `ContextMenu.SubmenuTrigger` and `ContextMenu.SubmenuContent` to create nested menus.

Supports its own `autocomplete` prop to enable search functionality within the submenu independently from the parent menu.

<auto-type-table path="./props.ts" name="ContextMenuSubMenuProps" />

### SubmenuTrigger

The trigger item for a submenu. Renders with a trailing chevron icon by default. Accepts `leadingIcon` and `trailingIcon` props.

When inside a searchable parent menu, the `value` prop can be used for autocomplete matching.

<auto-type-table path="./props.ts" name="ContextMenuSubTriggerProps" />

### SubmenuContent

The content container for a submenu. Shares the same API as `ContextMenu.Content` with a default `sideOffset` of `2`.

<auto-type-table path="./props.ts" name="ContextMenuSubContentProps" />

### Slots

Every rendered part carries a stable `data-slot` attribute for [styling and testing](/docs/styling#with-data-slot):

| Slot | Element |
|------|---------|
| `context-menu-trigger` | The `ContextMenu.Trigger` element |
| `context-menu-positioner` | Positioning wrapper around the content popup |
| `context-menu-content` | The `ContextMenu.Content` / `ContextMenu.SubmenuContent` popup |
| `context-menu-search-input` | The autocomplete search input (when `autocomplete`) |
| `context-menu-search-list` | Wrapper around items in autocomplete mode (when `autocomplete`) |
| `context-menu-item` | Each `ContextMenu.Item` |
| `context-menu-group` | `ContextMenu.Group` wrapper |
| `context-menu-label` | `ContextMenu.Label` |
| `context-menu-separator` | `ContextMenu.Separator` |
| `context-menu-empty-state` | `ContextMenu.EmptyState` |
| `menu-subtrigger` | `ContextMenu.SubmenuTrigger` (shared with `Menu`'s internals) |
| `menu-cell-leading-icon` | Leading icon inside an item or submenu trigger (when provided; shared with `Menu`'s internals) |
| `menu-cell-trailing-icon` | Trailing icon inside an item or submenu trigger (when provided; shared with `Menu`'s internals) |

### Autocomplete

To enable autocomplete, pass the `autocomplete` prop to the ContextMenu root element. Each menu instance will manage its own autocomplete behavior.

By default (`autocompleteMode="auto"`), items are automatically filtered as the user types. The filter matches against the item's `value` prop or its `children` text content.

For submenus, you can independently enable autocomplete by passing `autocomplete` to `ContextMenu.Submenu`.

## Accessibility

- Built on [Base UI Context Menu](https://base-ui.com/react/components/context-menu):
  the popup uses `role="menu"` and items use `role="menuitem"`, following the
  [WAI-ARIA Menu pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu/).
- Opens on right-click or long press (touch); focus moves into the menu when
  it opens and returns to the page when it closes with Escape.
- Arrow keys move through items, Enter activates the highlighted item, and
  ArrowRight/ArrowLeft open and close submenus.
- With `autocomplete`, the popup becomes a `role="dialog"` containing a search
  input, items render as `role="option"`, and focus stays in the input while
  arrow keys move the highlight — Escape first closes an open submenu.
- `ContextMenu.Label` must be wrapped in `ContextMenu.Group` so the group is
  labelled via `aria-labelledby`.
