## Anatomy

Import and assemble the component:

```tsx
import { Grid } from "@raystack/apsara";

<Grid>
  <Grid.Item />
  <Grid.Item />
</Grid>
```

## API Reference

### Root

Renders a CSS grid container.

<auto-type-table path="./props.ts" name="GridProps" />

### Item

Grid.Item is a wrapper component that must be a direct child of Grid. Use it when you need to customize the positioning or styling of individual grid items.

<auto-type-table path="./props.ts" name="GridItemProps" />

### Slots

Every rendered part carries a stable `data-slot` attribute for [styling and testing](/docs/styling#with-data-slot):

| Slot | Element |
|------|---------|
| `grid` | The grid container (or the element supplied via `render`) |
| `grid-item` | Each `Grid.Item` element |
