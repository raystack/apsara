## Anatomy

Import and assemble the component:

```tsx
import { Select } from "@raystack/apsara";

<Select>
  <Select.Label />
  <Select.Trigger>
    <Select.Value />
  </Select.Trigger>
  <Select.Content>
    <Select.Status />
    <Select.Empty />
    <Select.Group>
      <Select.GroupLabel />
      <Select.Item />
    </Select.Group>
    <Select.Separator />
  </Select.Content>
</Select>
```

## Usage

Appearance first, meaning size and variant, then how many items can be chosen, and who owns the value.

### Basic Select

A trigger and a list of items. `Select.Value` renders the current selection in the trigger. A check mark shows the selected item in the list. In multiple mode, each item has a checkbox instead.

Pass `items` to the root so `Select.Value` can show the label of the selected value. It takes `{ value, label }[]` or a value-to-label record. The list mounts only when it opens, so without `items` the trigger shows the raw value.

<Demo data={basicDemo} />

### Icon

Pass `leadingIcon` to `Select.Item` to show an icon before the item text.

<Demo data={iconDemo} />

To show the icon in the trigger too, pass a function as the child of `Select.Value`. It receives the selected value.

<Demo data={valueRenderDemo} />

### Label

`Select.Label` renders a visible label linked to the trigger. Clicking it focuses the trigger.

<Demo data={labelDemo} />

### Size

Two sizes. `medium` is the default; `small` fits toolbars and table filters.

<Demo data={sizeDemo} />

### Variant

`outline` (the default) draws a bordered control. `text` removes the border for use inside a toolbar or beside other text.

<Demo data={variantDemo} />

### With Separator

`Select.Separator` draws a rule between groups of items.

<Demo data={separatorDemo} />

### Multiple selection

To enable multiple selection, pass the `multiple` prop to the Select root element.

When multiple selection is enabled, the value, onValueChange, and defaultValue will be an array of strings.

<Demo data={multipleDemo} />

### Autocomplete

To enable autocomplete, pass the `autocomplete` prop to the Select root element.

With `items`, Base UI filters by label. Without `items`, the select filters items with a simple text match. For full control, set `autocompleteMode="manual"` and filter the items yourself.

`Select.Empty` shows its content only when no item matches the search. It needs `items` on the root. `Select.Status` is a polite live region for messages such as a result count or a loading state. Both work only in autocomplete mode.

<Demo data={autocompleteDemo} />

### Controlled

Pass `value` with `onValueChange` to own the selection. Do this when the value comes from a form, a URL, or another control on the page.

<Demo data={controlledDemo} />

### Slots

Every rendered part carries a stable `data-slot` attribute for [styling and testing](/docs/styling#with-data-slot):

| Slot | Element |
|------|---------|
| `select-trigger` | The trigger button that opens the menu |
| `select-trigger-content` | Flex wrapper around the trigger's children |
| `select-trigger-icon` | The chevron dropdown icon in the trigger |
| `select-label` | The label linked to the trigger |
| `select-value` | The `<span>` showing the selected label or placeholder |
| `select-value-content` | Wrapper around the chips in multiple mode |
| `select-value-overflow` | The "+N" overflow count for multiple values (when they don't all fit) |
| `select-positioner` | The floating positioner for the popup |
| `select-content` | The popup container |
| `select-search` | The search input (when autocomplete is enabled) |
| `select-list` | The scrollable list of items |
| `select-group` | A group of items |
| `select-group-label` | The label of a group |
| `select-empty` | The message shown when no item matches (autocomplete only) |
| `select-status` | The live region for status messages (autocomplete only) |
| `select-separator` | A divider between items or groups |
| `select-item` | An individual option row |
| `select-item-icon` | Leading icon on an item (when set) |
| `select-item-text` | The text label of an item |
| `select-item-indicator` | The check mark on the selected item (single selection only) |

## Accessibility

The Select component follows WAI-ARIA guidelines:

- Trigger has role `combobox`
- Content has role `listbox`
- Items have role `option`
- ARIA labels and descriptions
