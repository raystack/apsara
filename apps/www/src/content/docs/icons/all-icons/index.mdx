All 243 icons Apsara ships. 239 are drawn by [lucide](https://lucide.dev), and 4
are in-house SVGs that lucide cannot supply — `CoPilotIcon`, `CoinColoredIcon`,
`CheckCircleFilledIcon`, and `CrossCircleFilledIcon`.

Import any of them by name, and see [Usage](/docs/icons/usage) for sizing, colour,
and overrides.

```tsx
import { SearchIcon } from '@raystack/apsara/icons'
```

Click an icon to copy its name. The customizer changes how the grid draws them, so
you can preview a size and stroke before you commit to it.
